# 夸张动作复古毛毡人偶｜视觉验收标准

先检查硬门槛，再评分。硬门槛任一失败即需重做。

## 硬门槛

- 实际调用同时包含五张内置动作版参考图；不是纯文本生成。
- 只有一个新角色，性别表达、年龄、身份与动作符合用户请求。
- 若用户指定职业、工种或社会角色，画面至少具备两项互相印证的职业证据（专属工作道具、功能性服装细节、职业相关鞋履/足部装备）；道具用途、持握方式和动作逻辑清楚，不能以泛用装饰代替。
- 鞋履在鞋型、闭合方式、材质、颜色或职业功能上与参考图的高辨识度鞋履明显不同；未指定时，不得复用参考图中可辨认的靴型或其近似组合。职业需要包袋时，包袋必须具有可见的工作用途和差异化结构，不能只是泛用复古皮包。
- 动作具有一眼可辨的动态轮廓和节奏断点，不是普通直立摆拍；至少一只脚具有可信承重。
- 竖幅约 3:4，完整全身；头顶、双手、全部手指、双脚和必要道具均未裁切。
- 无可读文字、水印、logo、多余角色、多余肢体、重复手脚、明显错误的手或反向关节。
- 背景是完整铺满的暖浅蓝无缝棚拍背景，无舞台、舞池或室内外环境元素。

## 一致性评分

每项 0–2 分；非职业角色总分至少 16/18，职业角色总分至少 18/20；“手作媒介”“夸张动作”“比例轮廓”“棚拍系统”均须为 2 分。

| 项目 | 2 分标准 |
| --- | --- |
| 手作媒介 | 清楚读作实体定格动画人偶；陶土、羊毛毡、粗针织、灯芯绒、棉麻、旧皮革纹理可见；不是光滑 CGI |
| 夸张动作 | 大胆轮廓、折线或反向扭转形成明确节奏；夸张但重心、承重与关节关系可信；肢体负空间清楚 |
| 比例轮廓 | 圆润大头约 1:3，四肢略修长，短小手指与略大耳朵形成同一家族轮廓 |
| 面部语言 | 陶土颗粒、雀斑、手捏痕与自然不对称可见；眼眉嘴共同表达具体情绪 |
| 服装系统 | 低饱和复古配色，多层手工服装，真实车线、织纹和适度旧化；主色清晰 |
| 角色语义 | 性别表达、年龄、身份和动作能一眼读懂；必要道具少且互动可信 |
| 职业证据与差异化 | 职业角色由两项以上专属、功能明确的可见证据共同说明；鞋履与包袋（如有）服务职业且与样片高辨识度单品明显不同，不是只给样片换色 |
| 棚拍系统 | 暖浅蓝无缝墙地、柔和自然漫射光、极淡落地阴影，与样片摄影语言一致 |
| 构图完成度 | 3:4 竖幅、单人全身、主体够大、留白舒适；所有肢体和道具完整入画 |
| 新角色独立性 | 与五个参考角色的脸、职业、穿搭、配色、道具和具体姿势明显不同，但属于同一系列 |

## 迭代规则

每轮只处理得分最低的一项；保留已经通过的主体、动作方向、配色、构图和材质不变量。职业角色若“职业证据与差异化”低于 2 分，优先修正该项。每次重试仍须传入全部五张参考图，并逐字复述两个锁定段落。通过全部硬门槛且达到 18/20 后方可交付；非职业角色不评分“职业证据与差异化”，仍以 16/18 为阈值。
